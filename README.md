# C Programming Learning Path (Zero → MIT Professional Level)

This roadmap is organized in the exact learning order you requested.  
Each module is designed to be taught with:
- a beginner-friendly conceptual explanation,
- a C99+ code example with detailed inline comments,
- a short practice challenge,
- and a **Pro Tip** (pitfall/best practice).

---

## Phase 1 — Foundations & Basics

### Module 1: Environment Setup & Tooling
- Install and configure IDE/editor options (e.g., Code::Blocks, VS Code, CLion).
- Understand compiler vs interpreter, GCC/Clang basics, and build-run workflow.
- Compile a first C99 program from IDE and terminal.

### Module 2: Program Structure in C
- Anatomy of a C program: `#include`, `main()`, statements, return codes.
- Role of source files (`.c`) and header files (`.h`).
- Create a simple multi-file console project structure.

### Module 3: Syntax Basics
- Comments (`//`, `/* ... */`), naming conventions, formatting habits.
- Core data types: `int`, `float`, `char`.
- Variables and constants (`const`), initialization and type safety.

### Module 4: Input/Output Fundamentals
- Output with `printf` (format specifiers and formatting).
- Input with `scanf` (addresses, format strings, validation basics).
- Build an interactive console mini-program.

---

## Phase 2 — Logic & Control Flow

### Module 5: Operators
- Arithmetic, assignment, comparison, and logical operators.
- Operator precedence and parentheses for clarity.
- Practical expression-building patterns.

### Module 6: Conditional Logic
- `if`, `else if`, `else`, and nested conditions.
- Decision trees and defensive condition checks.
- Refactor repeated checks into clearer branching logic.

### Module 7: Switch-Case for Multi-Branch Decisions
- `switch`, `case`, `default`, `break` behavior.
- Menu-driven program design.
- Common fall-through mistakes and intentional fall-through usage.

### Module 8: Iteration & Loop Control
- `while`, `for`, and `do-while` loops.
- Loop boundaries, counters, and termination safety.
- `break` and `continue` for flow control.

---

## Phase 3 — Intermediate Topics

### Module 9: Arrays & Strings
- 1D and 2D arrays, indexing, bounds discipline.
- Character arrays and C strings (`'\0'` termination).
- Basic string processing patterns.

### Module 10: Functions
- Function declaration vs definition.
- Parameters, return types, scope, and modular decomposition.
- Pass-by-value vs pointer-based pass-by-reference style.

### Module 11: Recursion
- Base case and recursive case design.
- Stack behavior and recursion tracing.
- Recursion vs iteration trade-offs.

### Module 12: Pointers & Dynamic Memory
- Address-of (`&`), dereference (`*`), pointer arithmetic basics.
- `malloc`, `calloc`, `realloc`, `free`.
- Null checks, ownership, leaks, and dangling-pointer prevention.

---

## Phase 4 — Advanced Proficiency

### Module 13: Structures & Unions
- Designing custom data types with `struct`.
- Memory-sharing behavior of `union`.
- Modeling real-world records cleanly.

### Module 14: File I/O
- Open/read/write/append/close files using standard library APIs.
- Text vs binary file handling.
- Error handling with return values and `perror`.

### Module 15: Preprocessor Directives & Macros
- `#include`, `#define`, macro parameters.
- Header guards and conditional compilation.
- Macro pitfalls and safer alternatives where appropriate.

### Module 16: Basic Data Structures in C
- Linked lists (node design, insertion/deletion traversal).
- Stack and queue implementations (array-based and/or linked).
- Complexity awareness and memory correctness.

### Module 17 (Professional Extension): System Programming Basics
- Interfacing with OS-level APIs.
- Intro to process/thread concepts and synchronization fundamentals.
- Portability and safety considerations.
